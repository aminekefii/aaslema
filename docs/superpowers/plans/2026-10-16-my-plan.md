# My Plan Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make "Add to plan" save destinations to a personal plan in Supabase (toggle on the destination page) and list them in a new "My plan" profile dashboard section.

**Architecture:** `012_city_plans.sql` adds `city_plans`, a copy of the `city_visits` pattern. `CityDetail` toggles it with the existing `toggleFlag`/`setCityFlag`, loading the plan separately from likes/visits. Visited destinations' page becomes a shared `CityListSection` used by both Visited destinations and My plan.

**Tech Stack:** React 18 + Vite, Supabase (table + RLS), Vitest, lucide-react 0.460.

**Spec:** `docs/superpowers/specs/2026-10-16-my-plan-design.md`

## Global Constraints

- SQL `backend/supabase/012_city_plans.sql`, after 004; safe to re-run.
- Toggle only on the destination page; dashboard is view only; marking visited does not touch the plan.
- Sidebar: My moments, My plan (`/app/profile/plan`, `Calendar`), Visited destinations, Edit profile, Rate your trip.
- Copy (exact): "Add to plan", "In your plan", "Couldn't load your plan. Please refresh the page.", "My plan", "N destinations in your plan" / "1 destination in your plan", "Your plan is empty. Open a destination and click Add to plan.", "Added", "Loading…", "Couldn't load this list.", "Try again", "Explore destinations"; Visited keeps "Visited destinations", "N of 24 destinations visited", "You haven't marked any destinations as visited yet.", "Visited".
- A failing plan load must not block likes and visits.
- API functions never throw. Tests: Vitest, pure functions; from `frontend/`: `npx vitest run`.
- Style: 2-space indent, no semicolons, single quotes, short "why" comments.

## Review Focus

```js
// Profile lists (visits, plan): rows (newest first) → cards; ids no longer in the list are skipped
export function myCityCards(rows, cityList) {
  return rows.flatMap((row) => {
    const city = cityList.find((c) => c.id === row.city_id)
    return city ? [{ id: city.id, name: city.name, title: city.title, image: city.image, at: row.created_at }] : []
  })
}
```

```js
// The signed-in user's rows of city_visits or city_plans with their dates, newest first; null if loading failed
export async function fetchMyCityRows(table) {
  if (!supabase) return null
  try {
    const { data, error } = await supabase.from(table).select('city_id, created_at').order('created_at', { ascending: false })
    return error ? null : (data ?? [])
  } catch {
    return null
  }
}
```

Create `frontend/src/sections/CityListSection.jsx`:

```jsx
import { useCallback, useEffect, useState } from 'react'
import { cities } from '../cities.js'
import { fetchMyCityRows } from '../cityActivity.js'
import { myCityCards } from '../cityCounts.js'
import { timeAgo } from '../timeAgo.js'

// Profile dashboard list of destinations from one of the user's tables (visits or plan), newest first;
// each card opens the destination.
export default function CityListSection({ table, title, countText, emptyText, dateLabel }) {
  // undefined while loading, null if loading failed
  const [items, setItems] = useState(undefined)

  const load = useCallback(async () => {
    setItems(undefined)
    const rows = await fetchMyCityRows(table)
    setItems(rows && myCityCards(rows, cities))
  }, [table])

  useEffect(() => {
    document.title = `${title} - Aaslema`
  }, [title])

  useEffect(() => {
    load()
  }, [load])

  return (
    <>
      <h1>{title}</h1>
      {items && <p className="profile-card__lead">{countText(items.length)}</p>}
      {items === undefined && <p className="profile-note">Loading…</p>}
      {items === null && (
        <p className="profile-note profile-note--error my-moments__error" role="alert">
          Couldn't load this list.
          <button type="button" className="btn btn--primary btn--sm" onClick={load}>Try again</button>
        </p>
      )}
      {items?.length === 0 && (
        <p className="profile-note">{emptyText} <a href="/app/destinations">Explore destinations</a></p>
      )}
      {items?.length > 0 && (
        <div className="my-moments">
          {items.map((c) => (
            <a key={c.id} href={`/app/destinations/${c.id}`} className="my-moment">
              <img src={c.image} alt="" className="my-moment__photo" />
              <div className="my-moment__body">
                <strong>{c.name}</strong>
                <p className="my-moment__title">{c.title}</p>
                <time dateTime={c.at} className="my-moment__footer">{dateLabel} {timeAgo(c.at).replace('Just now', 'just now')}</time>
              </div>
            </a>
          ))}
        </div>
      )}
    </>
  )
}
```
